## 用户质疑后澄清（重要：工具能力边界）

用户连续质疑调试方案有效性，澄清结论：
1. **插件无法开启 WebView 调试**：`setWebContentsDebuggingEnabled` 是 Android 原生 API，插件跑在 JS 层够不到。release 版 Tavo 大概率没开 → chrome://inspect 大概率死路。
2. **Eruda 能力边界**：页面内自绘 DevTools（Console/Elements/Network/Resources），**没有 Sources 断点**，只能观察+改 DOM，不能断点单步。需打包前注入插件 HTML，调试完删。
3. **Tavo 内置 JS 控制台**：仅日志查看器（console.log/error 输出），无 DOM/Network/断点。
4. **测试台 vs 直接打开 HTML**：区别只在 mock_tavo.js 提供了 window.tavo 假 API + 事件/消息模拟；纯静态插件两者无区别（用户质疑正确）。注意测试台必须走 http://（file:// 会因 CORS 加载不了插件 HTML）。
5. **终极方案（README 已加）**：apktool 反编译 Tavo APK → smali 加 `setWebContentsDebuggingEnabled(true)` → 重打包签名 → chrome://inspect 完整 DevTools。代价：每次更新重来、签名变化清数据、可能有完整性校验闪退。
6. **mock_tavo.js 局限**：API 形状基于文档摘要推断，未在真实 Tavo 验证，可能不完整/不一致。

### Frida 路线判定：不可行
非 root 设备上 frida-server 只能 attach debuggable=true 的 app；Tavo 非 debuggable → Frida attach 不上。即使装 frida-server 也没用。

### 剩余可行调试路径
1. **adb logcat**（零成本）—— 看原生层 JS 异常/Flutter 日志，WebView console 需 Tavo 转发才可见
2. **反编译 APK 开 WebView 调试**（终极）：apktool 解包 → smali 加 `setWebContentsDebuggingEnabled(true)` + manifest 设 debuggable=true → 重打包签名 → 卸载重装（清数据）→ chrome://inspect 可用
3. **Eruda 注入插件 HTML**（改自己的插件，真机看 DOM/Console，无断点）
4. **Tavo 内置 JS 控制台**（看日志）

- 写通用打包脚本 `debug/inject_eruda_pack.py`：
  - 用法：`python inject_eruda_pack.py <plugin_dir> <output.tpg>`

- 已打包 `toonflow_story_style_eruda.tpg`（135KB，HTML 5KB→488KB）并 adb push 到手机 /sdcard/Download/
- 验证：unzip -p 确认 eruda.init 在 HTML 内（2 处命中）

### 安装与使用
1. Tavo → 设置 → 插件 → 从文件安装 → 选 /sdcard/Download/toonflow_story_style_eruda.tpg
2. 装完进聊天页，Eruda 悬浮按钮会出现在页面右下角
3. 点开有 Console / Elements / Network / Resources 面板（无断点单步）
4. 换插件调：`python inject_eruda_pack.py ../plugins/<其他插件> <输出>.tpg`

### 独立 Eruda 调试插件（21:33 用户要求，已完成）
- 用户要"把 Eruda 做成独立插件" → 建 `plugins/toonflow_story_debug_eruda/`
- 关键架构事实（重读 sandbox.js 确认）：插件 iframe 与宿主**同源**（`const a=window.parent` 且直接访问 `a.tav.sandbox.*`，非 postMessage）→ 可从插件 iframe 注入脚本到 `window.parent.document`
- 因此独立 Eruda 插件把 Eruda 注入到 **window.parent.document**，Elements 能看到**整个 WebView**（宿主聊天页 + 所有插件 iframe），比注入单个插件强
- 构建脚本：`debug/build_eruda_plugin.py`（读 debug/eruda.min.js 464KB 内联进 ui/eruda_debug.html，转 JS 字符串字面量注入 parent；带 __erudaDebugInjected 防重复；CSP/跨域失败回退自身 iframe）
- manifest 校验 `tavo_plugin_validate_manifest` ok=true；MCP 安装成功：com.toonflow.story-debug-eruda v1.0.0 enabled=True
- 风险：若 Tavo 宿主 CSP 禁止动态 inline script，parent 注入会被拦，回退到自身 iframe（只看到空 iframe）——届时走 APK 反编译改宿主 index.html

### 反编译 APK 抽取 WebView 静态资源（重大进展）
- `adb pull` Tavo `base.apk`(48MB) 到 `debug/tavo_app_webview/`，直接解压（APK=ZIP）抽 Web 层
