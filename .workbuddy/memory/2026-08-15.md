## 用户质疑后澄清（重要：工具能力边界）

用户连续质疑调试方案有效性，澄清结论：
1. **插件无法开启 WebView 调试**：`setWebContentsDebuggingEnabled` 是 Android 原生 API，插件跑在 JS 层够不到。release 版 Tavo 大概率没开 → chrome://inspect 大概率死路。
2. **Eruda 能力边界**：页面内自绘 DevTools（Console/Elements/Network/Resources），**没有 Sources 断点**，只能观察+改 DOM，不能断点单步。需打包前注入插件 HTML，调试完删。
3. **Tavo 内置 JS 控制台**：仅日志查看器（console.log/error 输出），无 DOM/Network/断点。
4. **测试台 vs 直接打开 HTML**：区别只在 mock_tavo.js 提供了 window.tavo 假 API + 事件/消息模拟；纯静态插件两者无区别（用户质疑正确）。注意测试台必须走 http://（file:// 会因 CORS 加载不了插件 HTML）。
5. **终极方案（README 已加）**：apktool 反编译 Tavo APK → smali 加 `setWebContentsDebuggingEnabled(true)` → 重打包签名 → chrome://inspect 完整 DevTools。代价：每次更新重来、签名变化清数据、可能有完整性校验闪退。
6. **mock_tavo.js 局限**：API 形状基于文档摘要推断，未在真实 Tavo 验证，可能不完整/不一致。

### AVD 系统语言改为简体中文（22:07 用户要求）
- AVD（emulator-5554, Pixel_8_Pro, Android 16）默认 en-US（ro.product.locale=en-US，persist.sys.locale 为空）

- 目的：让 Tavo UI 显示中文便于调试；Tavo 跟随系统语言，重开应用即生效（系统发 CONFIGURATION_CHANGED，自动重建）

## 修复「重启聊天后故事配置被清空 / 角色参数全空」（用户报 bug，已定位并全量修完）

1. **`tavo.get(name)` 返回包装对象未解包**：真实数据在 `.value`，形状 `{target,name,found,value}`。
