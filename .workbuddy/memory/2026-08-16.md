### 给用户的验收步骤（需在其本地有 LLM 的实例上做）
1. 手机打开该故事聊天（触发 chat:opened 建静态卡），确认 tavo App 已配置可用 LLM 提供方。
2. 对话若干轮（或命中关键字 记忆管理/更新/获得/等级/休息…）触发自动记忆刷新；或点侧栏「记忆已刷新」；或发 `@记忆管理 更新所有人的当前行为`。
3. 发 `@事件进度检测 下个事件` / `@下个章节` 验证章节推进。
4. 检查侧栏信息面板是否显示 HP/MP/等级/【当前行为】；发 `@红缥缈 你为何拦我` 验证 @角色 指名编排（@agent 能力，由 multi_character_stage 的 overrideScenario 实现）。

### 注意事项
- 手机 vs 模拟器是不同实例、chat id 不通用（手机 chat 8 / 模拟器 chat 2）。要上真机需手机连同 WiFi 或保持 `adb forward`，且改 `.env` 主配 IP。
