# 发送后的大概流程
输入“@记忆管理 更新全部角色的当前行为”-》发送-》
清掉input-》发送中效果-》
sendmsg:{
意图识别（关键词/llm识别）
-》记忆管理意图-》调用记忆管理agent ->返回json 数据
-》更新动态参数，主要是全部角色的 关键信息里多了当前行为信息
-》发送中效果取消
} ui:刷新信息面板的数据：storyinfo(各种变量)
-》开始下次剧情编排-发送编排请求
-》
orchestration:{
线上编排中效果-》调用章节判定agent (如果结束章节直接切换章节，加载下个章节的数据，如果判断为章节失败直接返回弹窗：章节已失败)->调用事件进度agent（最好一个章节了没有事件了没有章节结束条件就是自由模式了）->事件进度json ->调用剧情编排agent
}
-》返回编排数据-》编排中效果取消-》
角色发言气泡or 用户输入回合 -》
调用台词生成请求-》
streamlines：{
生成流式的台词
}
-》台词转语音中效果
-》
streamvoice{调用语音api}
->生成语音->播放语音完毕（包括播放失败）
-》下次剧情编排。-》orchestration。。。
