## 一、"Toonflow game "完整流程

```
用户发送 "@记忆管理 更新全部角色的当前行为"
  ↓
sendmsg → 意图识别（关键词/LLM）
  ↓ memory_manager
  调用 story-memory agent → 返回 JSON 数据
  更新动态参数（角色关键信息新增当前行为）
  ↓
发送中效果取消
  ↓
UI 刷新 storyinfo（各种变量）
  ↓
开始下次剧情编排 → 发送编排请求
  ↓ orchestration
  线上编排中效果
  → 调用章节判定 agent（story-chapter）
    → 结束章节 → 切换章节、加载下个章节数据
    → 章节失败 → 返回弹窗
  → 调用事件进度 agent（story-event-progress）
    → 事件进度 JSON
  → 调用剧情编排 agent（story-orchestrator-compact）
  ↓
返回编排数据 → 编排中效果取消
  ↓
角色发言气泡 OR 用户输入回合
  ↓
调用台词生成请求
  ↓ streamlines
  生成流式台词（逐句 NDJSON）
  ↓
台词转语音中效果
  ↓ streamvoice
  调用语音 API → 生成语音 → 播放语音完毕
  ↓
下次剧情编排（orchestration...）
```

### 开场白后流程

```
introduction
  ↓
streamlines：生成流式台词
  ↓
streamvoice：调用语音 API → 播放语音完毕
  ↓
下次剧情编排（orchestration...）
```

## 二、两阶段编排架构

### 阶段一：story-orchestrator-compact（JSON 计划）

**入参（JSON snapshot）：**

| 字段 | 来源 | 说明 |
|---|---|---|
| `world.name` | 固定 | 世界名 |
| `world.worldGlobalBackground` | `tf_story.edit.globalBackground` | 全局背景 |
| `chapter.title` | `tf_story.edit.chapters[i].title` | 章节标题 |
| `chapter.directive` | `tf_story.edit.chapters[i].background` | 章节指令 |
| `chapter.opening` | `tf_story.edit.chapters[i].openingLine` | 章节开场 |
| `roles` | `chat.characters` + roleType | 在场角色列表 |
| `wildcard_roles` | 固定 | `[{name:'某女子',role_type:'general'},{name:'某男子',role_type:'general'}]` |
| `current_event` | `tf_progress.phases[currentPhase].events[currentEvent]` | 当前事件 |
| `turn_state.can_player_speak` | 计算 | 最后一条是否是用户 |
| `turn_state.last_speaker` | 最近消息 | 上一说话人 |
| `turn_state.allowed_speakers` | roles 去掉用户 | 可发言角色 |
| `recent_dialogue` | 最近 N 条消息 | 角色：台词格式 |
| `latest_player_message` | 用户输入 | 最新玩家消息 |
| `free_mode` | `tf_progress.sessionFreeMode` | 是否自由模式 |

**输出（JSON）：**

```json
{
  "speaker": "萧炎",
  "role_type": "npc",
  "motive": "对主角的修炼速度表示惊讶",
  "await_user": false,
  "trigger_memory_agent": false,
  "event_adjust_mode": "keep",
  "event_status": "active",
  "event_summary": "第1章 > 新手村",
  "event_facts": ["第1章 > 新手村 > 对话1"]
}
```

### 阶段二：story_speaker（台词正文）

**入参：**

| 字段 | 来源 |
|---|---|
| 角色动态参数卡 | `tmm_story.characters`（来自记忆管理器） |
| 当前事件 | `tf_progress.phases` 当前 phase + event |
| 下一事件 | `tf_progress.phases[currentPhase].events[currentEvent+1]` |
| 世界知识 | `lorebook` constant 条目 |
| 说话人/动机 | 来自阶段一输出 |

**输出：** 角色台词正文（40~80字，最多2句）

## 三、逐句 TTS 播放

- `splitSpeechSegments`：按 `。！？.?!` 拆分，保留小括号内动作描写完整
- 逐句串行播放：等 `audio.onended` 才播下一句
- 上一句失败 → 停止整条消息播放，invalidate voiceId

---

## 四、await_user / trigger_memory_agent 语义

### await_user=true
- 编排器判定当前轮次需要等待用户输入
- 停止生成，不 append 消息
- 等下一轮用户发言才继续

### trigger_memory_agent=true
- 编排器判定当前回合记忆变化较大，需要立即刷新
- 调用 `window.tmmIntent.refresh()` 后台异步刷新记忆
