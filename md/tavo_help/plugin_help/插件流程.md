架构整合（MCS 中心枢纽）
用户发言
  ↓
编排插件 input:beforeSend 接管
  ↓ ① 意图识别（keyword/LLM）
     ├─ @记忆管理 → memory_manager 让出
     ├─ @事件进度 → event_manager 让出
     └─ 普通对话 → 进入编排
  ↓ ② 并行获取状态
     ├─ tfStoryJudge.checkAndAdvance() → 章节+事件状态
     ├─ buildMemoryContext() → 角色参数卡（HP/等级/当前行为）
     └─ tmmIntent.refresh() → 异步触发记忆刷新
  ↓ ③ 编排 Agent（阶段一）→ JSON
  ↓ ④ 发言 Agent（阶段二）→ 台词
  ↓ ⑤ tavo.message.append
  ↓ voice 插件播放 → 循环编排

## 通知其他插件
// 直接插入内容改成
await tavo.message.append({
role: 'assistant',
characterName: role,
content: text,
hidden: false,
});
  
改成：
event_manager 加载 → 注册 window.tf_story_on / tf_story_emit 事件总线
playChapterOpening() → window.tf_story_emit('opening', {role, text})
                            ↓
speaker 加载 → window.tf_story_on('opening', handler) 监听
                            ↓
handler → tavo.message.append() → 气泡UI + 语音

### 插件是否可以互相调用
可以，方式有三种：

调用方式	示例	说明
window 共享接口	window.tmmIntent.refresh() (mcs→tmm)	暴露在 window 上的函数，直接调
tavo 事件系统	tavo.plugin.on('tf_story:check_chapter', fn)	监听/发送自定义事件
tavo 变量读写	tavo.set('tmm', state, 'chat')	通过变量传递数据
LLM 通道	window.tf_llm.callDirect(...)	插件统一用同一个 LLM 通道
