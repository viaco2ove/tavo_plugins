

找到问题了！之前的指导有误——MCP 协议调用工具**不是直接把工具名当作 method**，而是通过 **`tools/call`** 方法来调用。

你的 `tools/list` 响应里列出的每个工具，它们的 `name`（如 `tavo_character_search`）应该放在 `params.name` 里，而 `method` 固定填 `tools/call`。

### 正确的 curl 写法

```bash
curl -s -X POST http://127.0.0.1:7347/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 28pd43" \
  -d '{
    "jsonrpc": "2.0",
    "id": 4,
    "method": "tools/call",
    "params": {
      "name": "tavo_character_search",
      "arguments": {
        "query": "Alice",
        "match": "exact",
        "limit": 10
      }
    }
  }' | jq .
```

 "match": "exact",

### 关键区别

| 之前错误的写法 | 正确的写法 |
|---|---|
| `"method": "tavo_character_search"` | `"method": "tools/call"` |
| 参数直接放在顶层 `params` | 参数放在 `params.arguments` 里，`params.name` 指定工具名 |

### 其他工具调用示例

**获取角色详情（`tavo_character_get`）：**
```bash
curl -s -X POST http://127.0.0.1:7347/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 28pd43" \
  -d '{
    "jsonrpc": "2.0",
    "id": 5,
    "method": "tools/call",
    "params": {
      "name": "tavo_character_get",
      "arguments": {
        "id": 1
      }
    }
  }' | jq .
```

参数说明
```json
 {
                "name": "tavo_character_search",
                "description": "Search Tavo assets by name. Use this before get/update when the id is unknown.",

                    "type": "object",

                        "query": {
                            "type": "string"
                        },

                                "exact",

                                "suffix",
                                "contains"

                            "type": "integer",
                            "minimum": 1,
                            "maximum": 100

                            "type": "integer",

}
```

**创建角色（`tavo_character_create`）：**
```bash
curl -s -X POST http://127.0.0.1:7347/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 28pd43" \
  -d '{
    "jsonrpc": "2.0",
    "id": 6,
    "method": "tools/call",
    "params": {
      "name": "tavo_character_create",
      "arguments": {
        "character": {
          "name": "测试角色",
          "description": "这是一个测试角色",
          "first_mes": "你好，我是测试角色。"
        }
      }
    }
  }' | jq .
```

**总结：所有 95 个工具都统一用 `"method": "tools/call"` 来调用，工具名放在 `params.name` 里即可。** 之前轮次的指导有误，抱歉！
