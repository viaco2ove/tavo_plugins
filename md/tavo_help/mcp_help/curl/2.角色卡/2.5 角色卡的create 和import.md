根据 `1.get_tools_result.json` 中的工具定义，`tavo_character_create` 和 `tavo_character_import_card` 的核心区别如下：

### 1. `tavo_character_create`
-   **用途：** 通过**结构化参数**手动构建一个新角色卡。
-   **输入方式：** 直接传递 CCv3 规范定义的各个字段作为独立参数，例如：
    -   `name` (string)
    -   `description` (string)
    -   `first_mes` (string)
    -   `personality` (string)
    -   `scenario` (string)
    -   `mes_example` (string)
    -   `creator_notes` (string)
    -   `system_prompt` (string)
    -   `tags` (array of strings)
-   **特点：** 适合程序化生成或从零开始构建角色，需要调用方自行组装每个字段。**不支持直接传入完整的卡片文件或 base64 头像数据**。
-   **头像支持：** ❌ 无 `avatar` 参数，无法在此接口中设置头像。

### 2. `tavo_character_import_card`
-   **用途：** 通过**导入现有卡片文件/数据**来创建角色。
-   **输入方式：** 接受一个完整的角色卡载体，支持以下格式：
    -   Full CCv2/CCv3 cards
    -   SillyTavern character wrappers
    -   （隐含支持 PNG 卡片、JSON 文件等标准格式）
-   **特点：** 适合迁移已有角色、使用社区分享的角色卡，或导入包含完整元数据（包括头像、自定义扩展字段等）的卡片。**卡片内嵌的所有数据（包括头像）会被自动解析和应用**。
-   **头像支持：** ✅ 如果导入的卡片文件本身包含头像数据（如 PNG 卡片的图像层、JSON 中的 `avatar` 字段或 base64 编码），则头像会被自动设置。

### 📌 总结对比表

| 特性                | `tavo_character_create`       | `tavo_character_import_card`        |
| :------------------ | :---------------------------- | :---------------------------------- |
| **输入形式**        | 分散的结构化字段参数          | 完整的卡片文件/数据对象             |
| **适用场景**        | 程序化创建、自定义构建        | 迁移、导入社区卡片、保留完整元数据  |
| **头像设置能力**    | ❌ 不支持                     | ✅ 依赖卡片文件自身是否包含头像数据 |
| **扩展字段保留**    | ❌ 仅支持预定义字段           | ✅ 保留卡片内所有原始数据           |
| **数据来源**        | 调用方逐字段提供              | 外部卡片文件                        |

### 💡 针对头像问题的建议
如果您希望**在创建角色时一并设置头像**，应优先选择 `tavo_character_import_card`，并确保导入的卡片文件（如 CCv3 JSON 或 PNG 卡片）中已包含正确的头像数据。而 `tavo_character_create` 仅适用于不需要头像或后续再通过其他方式补充头像的场景。


## 那么都是新卡？
是的，**两者都是用于创建新角色卡**，不会修改或覆盖已存在的角色。

具体说明如下：

-   **`tavo_character_create`**：通过传入结构化字段（name、description 等）**新建**一个角色卡。
-   **`tavo_character_import_card`**：通过导入完整的 CCv2/CCv3 卡片文件或 SillyTavern 包装器**新建**一个角色卡。

两个接口的描述中均明确使用 “Create a new character card” / “Import and create a new character card” 的措辞，且**均未提供 character_id 或类似标识符参数**来指定目标角色，因此它们的作用仅限于**新增**，不具备更新、替换或合并已有角色的功能。

### 📌 补充说明
若需修改已存在的角色卡（除头像外），应使用 `tavo_character_update`；但如前所述，该接口**不支持头像设置**。因此：
-   **新建带头像的角色** → 用 `tavo_character_import_card`（推荐）或 `tavo_character_create`（无头像）。
-   **修改已有角色的文本信息** → 用 `tavo_character_update`。
-   **修改已有角色的头像** → **当前 MCP 工具集中无对应接口**，只能通过应用内手动操作或其他非 MCP 途径实现。
