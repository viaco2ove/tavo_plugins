MCP 走 HTTP JSON-RPC，Bearer token 为 `28pd43`（来自 .env）。以下是全套 curl 命令：

**1. 读取红缥缈 858 当前完整卡**
```bash
curl -s -X POST http://127.0.0.1:7347/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 28pd43" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"tavo_character_get","arguments":{"id":858}}}'
```

**2. 整卡导入带头像新卡**
```bash
curl -s -X POST http://127.0.0.1:7347/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 28pd43" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"tavo_character_import_card","arguments":{"card":{"spec":"chara_card_v3","spec_version":"3.0","data":{"name":"红缥缈","description":"<完整 description>","first_mes":"","personality":"NPC","extensions":{"tavo_chat":"测试-谁让这个山大王修仙的 · 第1章"},"avatar":"files/global/红缥缈.png"}}}}}'
```
→ 返回 `characterId`（新 id，如 871）

**3. 重绑 chat7 成员**（把 858 换成新 id，其余照旧）
```bash
curl -s -X POST http://127.0.0.1:7347/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 28pd43" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"tavo_chat_update","arguments":{"chatId":7,"chat":{"characterIds":[871,859,860,861,862,863,864,865,866,867,868,869]}}}}'
```

**4. 删除旧卡 858**
```bash
curl -s -X POST http://127.0.0.1:7347/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 28pd43" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"tavo_character_delete","arguments":{"id":858}}}'
```

**5. 回读新卡验证头像**
```bash
curl -s -X POST http://127.0.0.1:7347/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 28pd43" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"tavo_character_get","arguments":{"id":871}}}'
```

要点：
- step 1 的 `description` 要原样带入 step 2，不然角色设定会丢（第1步输出里 `data.description` 就是）
- avatar 必须是 `files/global/红缥缈.png` 引用，不是 base64
- 直接 `character_update` 写 avatar 无效，已被服务端忽略（此前实测确认），所以必须走 import_card 换新卡
