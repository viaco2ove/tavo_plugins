## 三、关键设计特征

1. **统一的 CRUD 模式**：每个资源模块（character/lorebook/regex/preset/persona/theme）都遵循 `search → get → create → update → delete` 的标准操作模式，部分还支持 `import` 和 `entry_upsert/entry_delete` 的条目级操作。

2. **安全操作保护**：所有写操作（创建/更新/删除）均支持 `dryRun`（预演不保存）、`expectedRevision`（乐观锁冲突拒绝）、`clientRequestId`（幂等重试键）三个安全参数。

3. **多格式兼容**：角色/世界观/预设等模块均兼容 **CCv3**、**CCv2**、**SillyTavern** 多种格式，可无缝导入导出。

4. **三级作用域变量**：`variable` 模块支持 `global`（全局）、`chat`（会话级）、`message`（消息级）三个作用域，支持点路径和方括号路径访问嵌套值。

5. **聊天为核心**：绝大多数工具围绕"聊天"展开——聊天包含角色、人格、预设、世界观、正则、主题等配置，消息是聊天中的交互单元。

6. **扩展性**：插件系统支持打包、安装、卸载、配置管理，且可获取已启用插件的运行时贡献。

## 四、核心工作流

基于这些工具，典型的 Tavo MCP 使用流程为：

1. **tavo_status** → 检查服务器状态
2. **tavo_chat_search / tavo_chat_create** → 查找或创建聊天
3. **tavo_character_search / tavo_character_create** → 管理角色
4. **tavo_lorebook_search / tavo_lorebook_create** → 管理世界观
5. **tavo_input_set / tavo_input_send** → 发送消息
6. **tavo_message_find** → 获取回复消息
7. **tavo_generate** → 直接触发文本生成
8. **tavo_内部工具erate** → 生成图片
9. **tavo_tts_play** → 语音播放回复
