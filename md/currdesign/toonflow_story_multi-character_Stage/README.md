## 一句话定位

让 tavo 的群聊从「多个角色各说各话」变成「有编排的群戏」。

## 核心模块

1. **发言路由引擎** — 决定谁来说下一句话
2. **台词生成器** — 三档生成（T0 模板/T1 轻量/T2 高质量）
3. **区域聚焦系统** — 控制谁可以发言（不是地图）
4. **记忆协同** — 与 `toonflow_story_memory_manager` 联动

## 与 Toonflow-game 的关系

移植并简化自 Toonflow-game 的多 Agent 叙事引擎：

- `NarrativeOrchestrator.ts` → 编排师逻辑
- `SpeakerRouteEngine.ts` → 发言路由
- `区域设计.md` → 发言聚焦系统
- `角色发言.md` → 三档发言机制
- `记忆管理.md` → 三级记忆系统

## 版本计划

- **v1.0**：发言路由 + 基础台词生成 + 区域聚焦
- **v1.1**：NPC 自主发言 + 记忆协同优化
- **v2.0**：任务触发系统 + 关键剧情节点

## 依赖

- `com.toonflow.story-memory-manager` — 记忆管理器（可选但推荐）
- Tavo `specVersion 2`

## 设计原则

1. **插件化**：不依赖服务端，用 tavo 现有 API 实现
2. **轻量化**：优先规则路由，AI 仅在必要时调用
3. **可插拔**：与现有记忆插件协同
