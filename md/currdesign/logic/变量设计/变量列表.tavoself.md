# Tavo 自身 API / 变量 / 端点
结论：能获取的变量非常有限， 插件开发基本只能获取角色卡，世界书和各个插件的chat 变量和global 变量。
基本无法 获取 tavo 官方的变量。 例如llm 插件自己重新配置apikey 变量才能自己调用llm大模型。
> 通过浏览器控制台 `tavo.` 或插件内 `tavo.xxx` 访问。

---

## 变量 `tavo.get / tavo.set / tavo.unset`

```js
tavo.get('name')                         // 读 chat 变量
tavo.get('name', 'global')              // 读 global 变量
tavo.get('name', 'message')              // 读消息变量
tavo.get('name.hp')                     // 路径访问
tavo.set('name', value)                 // 写 chat 变量
tavo.set('name', value, 'global')        // 写 global
tavo.unset('name')                      // 删除
```

变量返回值是 `{target,name,found,value}` 包装对象，解包：
```js
let v = tavo.get('hp');
let guard = 0;
while (v && typeof v === 'object' && v.found !== undefined && 'value' in v && guard++ < 5) v = v.value;
```

# MCP 能否查到 tavo 的变量 —— 能 ✅

> 实测时间：2026-08-19（模拟器实例 `127.0.0.1:7347`，token 走 ADB 转发）。
> 探测脚本：`script/tavo_mcp_use/_probe_variable_tools.py`（列工具）/ `_dump_all_variables.py`（拉全部变量树）。

## MCP 变量工具（共 95 个工具中 5 个变量相关）

| 工具 | 作用 | 关键参数 |
|------|------|----------|
| `tavo_variable_list` | **列出整个变量树**（枚举入口） | `scope`: `global` / `chat`+`chatId` / `message`+`chatId`+(`id`\|`index`) |
| `tavo_variable_get` | 按路径读单个变量 | 同上 + `name`（支持 `a.b` 点路径） |
| `tavo_variable_set` | 写原始 JSON 值 | 同上 + `name` + `value` |
| `tavo_variable_update` | 浅合并对象 / 替换其他值 | 同上 + `name` + `value` |
| `tavo_variable_unset` | 删除变量路径 | 同上 + `name` |

**⚠️ 参数坑（实测）**：
- 全部用 **`chatId`**（整型），不是 `chat_id`；`tavo_chat_get` 却用 **`id`**——参数名不统一。
- `chatId` 必须整型，`"1"` 与 `1` 是不同作用域。
- 返回值在 `result.content[0].text`（JSON 字符串），形如 `{target:{scope,chatId}, variables:{...}}`，**`variables` 才是真身**。
- MCP 侧没有包装对象问题（那是 TavoJS `tavo.get` 的事），MCP 返回已解包。
- `tavo_chat_search` 空 query 返回空列表（与 `tavo_plugin_search` 同坑）——枚举 chat 要用 `tavo_current_chat_get` 或遍历 `tavo_chat_get {id: 1..N}`。

## 结论

1. ✅ MCP **能**枚举 tavo 全部变量：`tavo_variable_list` 按作用域返回完整变量树，无需提前知道变量名。
2. 变量全景：global 11 个根 + chat 1 的 13 个根，全部由 **tavo_plugins 自己创建**（`tf_*` / `tmm*` 前缀）；**tavo App 原生不预置任何 chat/global 变量**——变量树里没有非插件变量。
3. message 作用域可用但当前为空。
4. 变量读取铁律（`{target,name,found,value}` 包装解包）只影响 **TavoJS 侧**；MCP 侧返回已解包，直接取 `.variables`。
