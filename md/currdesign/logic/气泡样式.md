# 气泡的样式是用mcp 配置还是用插件配置？
气泡样式既不归"插件直接画"，也不是某个孤立的 MCP 字段——它属于 聊天主题（ChatTheme）
气泡（容器）的填充色、圆角、模糊、左右对齐、字体，都是 tavo 原生按 ChatTheme 渲染的，不是插件用 DOM 画的，也不是"气泡样式"专属 MCP 工具。两条配置路径最终都落到同一个 theme 对象上：

你想用什么配	工具/API	怎么落到一个聊天
MCP	tavo_theme_create（带 userBubble/characterBubble）→ tavo_theme_update	tavo_chat_update({ theme: <id> }) 绑定到群聊
插件（TavoJS）	tavo.theme.create(...) + tavo.theme.update(...)	在插件 runtime 里 tavo.chat.update({ theme })

# 用插件：toonflow_story_style
插件可调参数 
- 单条/多条模式
默认：单条只有最新一台台词显示 （其他哪些隐藏也好， 气泡完全透明化也好包括文字）
多条：就是tavo 的模式的基础上上，气泡上多显示发言者的迷你头像（如果可以的话）

- 气泡透明度（可调）
默认：35%
背景颜色：默认跟随主题
字体颜色：默认跟随主题
对齐方向：默认跟随主题
圆角大小：默认跟随主题
