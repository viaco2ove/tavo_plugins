# global 变量

> 记录在 `tavo_variable` 表的 `scope=global`。在 `tavo_chat_reset`（重置聊天）后仍然保留，是持久化数据的主存储。
> 大部分变量同时双写到 global 和 chat，以保证 reset 后的恢复能力。
> 全局变量是所有聊天共有的!
> 例如
> 错误示范：
> tf_story 是全局的数据，以下数据就不知道那个故事的了！
```json
{
  "intro": "故事简介（用户视角，第一人称）",
  "globalBackground": "全局背景（世界设定）",
  "orchestration": "编排模式，\"system\"=跟随系统 / \"plugin\"=角色编排插件",
  "currentChapterIndex": 0,
  "lineCount": 20,
  "chapters": [
    {
      "title": "第 1 章：穿越成山大王",
      "content": "## 苏醒\n### 穿越醒来\n@旁白：xxx...",
      "openingRole": "旁白",
      "openingLine": "xxx",
      "background": "files/chat/chapter_bg_1.jpg",
      "successCondition": "财气眼激活",
      "conditionVisible": true,
      "events": [],
      "enabled": true
    }
  ]
}
```
应该改为tf_story_{chat_id}

**用途**：故事完整配置（同步入口 + 编辑器数据源）

  "globalBackground": "全局背景（世界设定）",
  "orchestration": "编排模式，\"system\"=跟随系统 / \"plugin\"=角色编排插件",
  "currentChapterIndex": 0,
  "lineCount": 20,
  "chapters": [
    {
      "title": "第 1 章：穿越成山大王",
      "content": "## 苏醒\n### 穿越醒来\n@旁白：xxx...",
      "openingRole": "旁白",
      "openingLine": "xxx",
      "background": "files/chat/chapter_bg_1.jpg",
      "successCondition": "财气眼激活",
      "conditionVisible": true,
      "events": [],
      "enabled": true

## tf_llm

**用途**：LLM 参数配置（镜像 tavo「更多-模型设置」——官方变量读不到，故插件自建）
**字段**：
- `apiUrl` / `apiKey` / `apiMode` / `model`：接管调用时自带凭证；留空则 fallback `tavo.generate()`（黑盒，用 tavo 内置 key）
- `reasoningEffort`：none/minimal/low/medium/high，默认 `minimal`
- `temperature`：0.3，`topP`：0.5，`topK`：null，`maxTokens`：1500
- `memoryLength`：20（上下文记忆条数），`stream`：true（流式传输）
- `enabled`：true（总开关）
**结构**：
```json
{
  "enabled": true,
  "apiUrl": "",
  "apiKey": "",
  "apiMode": "",
  "model": "",
  "reasoningEffort": "minimal",
  "temperature": 0.3,
  "topP": 0.5,
  "topK": null,
  "maxTokens": 1500,
  "memoryLength": 20,
  "stream": true
}
```
memoryLength 这个参数暂时没用,是通过lineCount 来控制台词数量的。

**维护者**：`toonflow_story_llm_optimization`
**读取者**：MCS 编排阶段（`generation:prepare` 拦截注入参数）

## tmm_story_static_{chat_id}

**用途**：静态故事记忆（场景设定/角色性格，不频繁变化）
**结构**：
```json
{
  "summary": "xxx",
  "facts": ["角色关系...", "世界设定..."],
  "tags": ["修仙", "黑风寨"],
  "charParams": { "角色名": { "性格": "...", "背景": "..." } },
  "dynamic_world_global_background": "..."
}
```
**维护者**：`toonflow_story_memory_manager`（`writeVarDual`）
**读取者**：`toonflow_story_speaker`（注入角色动态状态到请求）
