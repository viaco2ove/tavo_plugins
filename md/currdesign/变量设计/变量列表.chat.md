## tmm / tmm_story

**用途**：运行时记忆状态（summary / facts / tags / charParams）
**结构**：
```json
{
  "summary": "对话摘要...",
  "facts": ["事实1", "事实2"],
  "tags": ["修仙", "冒险"],
  "charParams": {
    "角色名": { "性格": "...", "当前状态": "..." }
  },
  "dynamic_world_global_background": "当前场景的动态描述"
}
```
**维护者**：`toonflow_story_memory_manager`（chat:opened 初始化 / 对话后更新）
**读取者**：`toonflow_story_event_manager`（boot 检查 tmm 就绪后才放行用户发言）
**注意**：`tmm_story` 和 `tmm_story_static` 是静态版，`tmm` 是动态版；`toonflow_story_speaker` 优先读 `tmm_story`

## tf_last_speaker

**用途**：记录最后一个发言的角色名（供 sprite 插件判断当前立绘）
**值**：字符串，如 `"红缥缈"`
**维护者**：`toonflow_story_multi_character_stage`（编排成功后写入）

## tf_voice_config

**用途**：音色平台配置（插件配置，非 story 数据）
**结构**：
```json
{
  "voice_platform": "xiaomimimo",
  "voice_platform_apikey": "",
  "auto_play": true
}
```
**维护者**：`toonflow_story_voice`（`config.onChange` 保存）
**读取者**：`toonflow_story_voice`（平台切换时读取）

## 临时变量（会话内产生，不持久化）

| 变量名 | 用途 | 生命周期 |
|--------|------|----------|
| `tf_story.boot` | 启动状态（双写 global） | 启动完成后持续有效 |
| 消息内嵌数据 | 立绘/背景图片路径（`files/chat/*.png`） | 随消息持久化，不在变量表 |
