# toonflow_story_event_manager

故事信息面板与事件管理器插件：追踪章节进度、评估完成条件、自动推进章节。

## 功能

- 自动追踪当前章节和进度
- 评估完成条件（对话次数、获得物品、任务完成等）
- 条件满足时自动推进章节
- 显示故事进度面板
- 支持重新开始

## 使用方式

1. 先通过 MCP 或其他方式创建世界书（作为故事蓝图）
2. 世界书的非 constant entry 作为章节
3. 插件自动读取世界书并初始化故事状态
4. 每轮对话后自动评估完成条件

## completion_condition 格式

```
与萧炎对话3次;获得玄阶功法
```

支持的格式：
- `与XXX对话N次` - 计数条件
- `获得物品名` - 物品条件
- `完成XXX任务` - 任务条件
- 其他文本 - AI 评估
